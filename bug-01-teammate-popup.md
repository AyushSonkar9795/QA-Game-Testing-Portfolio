#  Bug 01: Teammate mode/event not displayed in pop-up alert intermittently

## 📌 Description

When the teammate activity pop-up appears, it is expected to display the current game mode or event the player is participating in. However, in some cases, the pop-up appears without showing any mode/event information.

## Steps to Reproduce

1. Launch the game
2. Join or create a team
3. Wait for teammate activity pop-up
4. Observe the displayed information
5. Repeat multiple times
   
## Environment
**Device**: Nothing Phone 1
**Software Info:** NOTHING OS 3.2
**Processor:** Qualcomm® Snapdragon 778G+
**RAM:** 8GB
**Storage:** 256GB
**Android Version:** 15



## ✅ Expected Result

Pop-up should always display teammate's current game mode/event

## ❌ Actual Result

Pop-up appears, but sometimes the mode/event information is missing

## Reproducibility

Intermittent

## Severity

Medium

## ⚠️ Priority

Medium
